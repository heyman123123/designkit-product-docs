# DesignKit PRD v0.1

## 1. 背景与目标

跨境卖家拥有商品原图，但从拍摄到可发布 Listing 图片耗时、返工多、素材难复用。产品提供商品视觉资产生产工作台。

### 目标

- 首个 SKU 在 10 分钟内获得可审核候选图。
- 让用户能追溯每张图的原图、分析、模型、版本和审核记录。
- 用真实 SKU 验证用户是否愿为按 SKU/高清导出付费。

## 2. 用户与场景

**P0**：5–30 人跨境卖家或 Amazon 运营，低风险商品，缺稳定设计资源。

**核心场景**：上新、活动改版、同一商品多场景变体、手机拍摄后电脑批量处理。

## 3. 信息架构

Web：工作台 / 项目 / 文件夹 / 资产 / 任务队列 / 结果审核 / QC / 导出 / 设置。

App：首页任务 / 拍摄上传 / 任务进度 / 审核 / 分享。

层级：Workspace → Project → Folder → SKU → Asset → AssetVersion。

## 4. P0 功能需求

### P0-01 项目与文件夹

用户可创建 Amazon 项目、SKU 和两级文件夹（SKU/批次），移动/归档素材。

**验收**：刷新和跨设备后层级不丢失；非成员不可读取。

### P0-02 上传

支持 Web 批量上传和 App 相机/相册上传；校验格式、大小、hash，生成缩略图。

**验收**：20 张图片成功率 ≥95%；失败可重试且不创建重复资产。

### P0-03 自动分析

输出主体、颜色、材质、属性、OCR、卖点建议、风险标签和平台规格建议；用户可以编辑分析结果。

**验收**：分析失败保留原图；结果可重试；分析状态持久化。

### P0-04 生成

生成三类模板：白底主图、生活场景图、卖点图。提交前展示 SKU 配额消耗。

**验收**：同一 SKU 生成中不可重复提交；幂等请求不重复扣费。

### P0-05 结果与版本

网格查看、原图/结果对比、通过/驳回、版本切换、回滚和批量操作。

**验收**：每个生成结果可追溯到输入版本、模型、提示词和操作者。

### P0-06 QC 与导出

检查尺寸、背景、主体完整性、文字、Logo/敏感风险、清晰度；通过后导出 Amazon 规格 ZIP。

**验收**：未通过 QC 的图片无法进入高清导出；扣费明细可核对。

### P0-07 App companion

拍摄/上传、进度、审核、备注、只读分享；审核状态与 Web 最终一致。

## 5. P1 / 后续

P1：第二品类、第二平台、标签和搜索、Team 角色、轻量裁剪、批量变体。

V2：自动发布、复杂编辑器、视频、企业 SSO、多模型路由。

## 6. 非功能需求

RLS 空间隔离；短期签名 URL；软删除；审计日志；失败重试；Sentry 监控；关键状态可恢复；主要 Web 流程支持键盘与焦点管理。

## 7. 埋点

`project_created`、`asset_uploaded`、`analysis_completed`、`generation_submitted`、`generation_succeeded`、`qc_approved/rejected`、`export_created`、`second_sku_created`、`paywall_viewed`、`subscription_started`。

## 8. 端到端验收

创建项目 → 创建 SKU → 上传 → 分析 → 确认 → 生成 → QC → 审核 → 高清导出；刷新页面、切换设备、网络失败、重复点击、过期分享和无权限访问均通过。
