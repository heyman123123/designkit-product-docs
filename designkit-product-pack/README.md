# DesignKit 全栈产品资料包

## 0. 项目定位

**产品名（工作名）**：DesignKit Commerce Visual OS

**一句话**：上传商品图，自动分析并生成 Amazon 可发布候选图片，再按店铺、SKU、批次和版本统一管理。

**MVP 目标**：只做 Amazon + 一个低风险品类；Web 负责生产管理，App 负责拍摄上传与审核。

## 2. 统一产品边界

### 做什么

上传原图 → AI 分析主体/属性/文字/风险 → 生成主图、场景图、卖点图 → 自动 QC → 人工确认 → 文件夹/版本管理 → Amazon 规格导出。

### 不做什么

首期不做多平台、多品类通用规则、自动发布 Amazon、无限生成、移动端完整画布、视频、复杂团队权限、开放素材市场和自动法律/合规承诺。

## 3. 成功标准（待真实用户验证）

- 上传成功率 ≥95%
- 任务成功率 ≥90%
- 导出成功率 ≥95%
- 首轮可发布率目标 ≥60%
- 主体关键属性一致率目标 ≥95%
- 文字准确率目标 ≥98%
- 7 日第二 SKU 复用率目标 ≥40%
- 图像生成成本 ≤订阅收入的35%

## 4. 首期决策待办

1. 从 3C 配件、家居收纳、宠物用品中冻结一个品类。
2. 冻结 Amazon 站点与图片规则版本。
3. 选择一家视觉分析/图像生成供应商并确认数据保留条款。
4. 冻结 SKU 配额与高清导出计费口径。
5. 收集 30–50 个真实 SKU，完成离线质量评测。
