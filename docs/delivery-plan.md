# 落地与上线

## 7 / 30 / 60 / 90 天

### 0–7 天：验证而非扩张

访谈 20 个目标用户；收集并获授权的真实 SKU；完成一个端到端人工/半自动样例；准备销售页、FAQ、案例和埋点。目标 5 次高清导出、2 个付费意向，不投广告。

### 8–30 天：MVP

完成 Amazon + 一个低风险品类的 Web 闭环：项目、SKU、文件夹、上传、分析、三类生成、QC、审核、版本、导出；App 完成拍摄、上传、进度、审核、分享。目标 100 试用、10 付费、收入 ≥$300。

### 31–60 天：付费与留存

接入配额/支付、成本告警、重试/取消、模板优化、基础 Team 能力。目标 300 试用、30 付费、MRR 约 $1,000，7 日第二 SKU 复用率 ≥40%。

### 61–90 天：谨慎扩张

只有质量、毛利和留存达标才扩第二平台或品类；增加标签搜索、批量变体和审批。目标 600 试用、60 付费、MRR 约 $2,500。

## 上线门禁

- 平台、品类和规则版本已冻结。
- 第三方 Logo、未授权肖像、敏感内容、虚假功效、主体变形和尺寸不合规 100% 阻断。
- 至少 20 个目标用户、5 次高清导出，全部人工复核。
- 上传、权限、分享、删除、审计、扣费和恢复测试通过。
- 检测服务不可用时默认人工复核，不放行。
- 投诉、下架、退款、删除和模型故障流程已演练。

## 测试清单

功能：上传、分析、重试、生成、取消、审核、版本、文件夹、导出、配额。

一致性：刷新、跨设备、Realtime、并发生成、重复点击、网络断开。

安全：RLS、越权访问、签名 URL 过期、软删除、分享过期、审计。

质量：主体、颜色、材质、OCR、Logo、背景、清晰度、Amazon 尺寸。

商业：试用、升级、余额不足、重复下载、失败不扣费、退款。

## 每周节奏

周一看漏斗、成本和质量；周二优化一个品类模板；周三访谈/交付；周四发布案例和教程；周五复盘可发布率、第二 SKU 复用、付费、退款与事故。每周只允许一个主要实验。
