# 产品需求文档 PRD v0.1

## 产品定义

DesignKit Commerce Visual OS 是面向跨境卖家和 Amazon 运营的商品视觉资产生产系统：上传商品图后自动分析并生成主图、场景图、卖点图，随后完成质量检查、审核、版本管理和平台规格导出。

## P0 用户与场景

- 5–30 人的跨境卖家或 Amazon 运营
- 3C 配件、家居收纳、宠物用品等低风险商品
- 上新、活动改版、同一 SKU 多场景变体
- 手机拍摄原图，电脑批量处理和导出

## 信息架构

Web：工作台 / 项目 / 文件夹 / 资产 / 任务队列 / 结果审核 / QC / 导出 / 设置。

App：任务 / 项目 / 拍摄上传 / 审核 / 我的。

数据层级：Workspace → Project → Folder → SKU → Asset → AssetVersion。

## P0 功能

### 项目、SKU 与文件夹

用户创建 Amazon 项目、SKU 和两级文件夹（SKU/批次），支持归档和资产移动。刷新页面、切换设备后层级不丢失，非成员不可读取。

### 上传与自动分析

Web 支持批量上传，App 支持相机和相册上传。服务端校验格式、大小和 hash，并生成缩略图。分析输出主体、颜色、材质、属性、OCR、卖点建议、平台建议和风险标签，结果可人工编辑。

### 图片生成

提供白底主图、生活场景图、卖点图三个模板。提交前展示 SKU 配额消耗；同一 SKU 生成中不可重复提交；幂等请求不重复扣费。

### 结果、QC 与导出

结果支持网格筛选、原图对比、版本切换、通过/驳回和批量操作。QC 检查尺寸、背景、主体完整性、文字、Logo/敏感风险和清晰度。未通过 QC 的图片不能进入高清导出。

### App companion

App 只承担拍摄/上传、任务进度、单图审核、备注和只读分享，审核状态与 Web 最终一致。

## P1 / 后续版本

第二品类、第二平台、标签和搜索、Team 角色、轻量裁剪、批量变体。V2 再考虑自动发布、复杂编辑器、视频、企业 SSO 和多模型路由。

## 非功能要求

Workspace 级数据隔离（应用层强制作用域 + 数据库 RLS 兜底）；短期签名 URL；软删除；审计日志；失败重试；Prometheus + Sentry 监控；关键状态可恢复；主要 Web 流程支持键盘、焦点管理和 aria-live。

## 埋点

`project_created`、`asset_uploaded`、`analysis_completed`、`generation_submitted`、`generation_succeeded`、`qc_approved`、`qc_rejected`、`export_created`、`second_sku_created`、`paywall_viewed`、`subscription_started`。

## 端到端验收

创建项目 → 创建 SKU → 上传 → 分析 → 确认 → 生成 → QC → 审核 → 高清导出；刷新页面、切换设备、网络失败、重复点击、过期分享和无权限访问均通过。

## 成功指标（待验证）

上传成功率 ≥95%；任务成功率 ≥90%；导出成功率 ≥95%；首轮可发布率目标 ≥60%；主体关键属性一致率目标 ≥95%；文字准确率目标 ≥98%；7 日第二 SKU 复用率目标 ≥40%。
