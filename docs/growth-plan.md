# 推广与商业化

## 首攻市场

首攻跨境中小卖家和 Amazon 运营，优先 3C 配件、家居收纳、宠物用品中的一个低风险品类。代运营和品牌团队作为第二阶段。

## 定价假设

| 方案 | 定价 | 说明 |
| --- | ---: | --- |
| Free | 免费 | 1 个 SKU 低清预览，带水印 |
| Starter | $19/月 | 低量 SKU，按量限制 |
| Growth | $49/月 | 推荐；更多 SKU 与高清导出 |
| Pro | $99/月 | 高用量和更多项目 |

可提供年付 8 折和按量包。预览、审核、失败重试不扣费；高清导出和 SKU 配额扣费；重复下载不重复扣费。

## 付费墙

不在上传前阻断。在高清导出、额度不足、批量超额、更多项目/成员时触发，展示本次消耗、已生成结果和升级后的额度。

## 获客渠道

1. 卖家社群：免费单 SKU 诊断和前后对比案例。
2. 服务商联合：与摄影、代运营、ERP/选品工具联合分发。
3. 内容 SEO：Amazon 主图尺寸、Listing 图片模板、上新效率等高意图主题。
4. 直接销售：定向联系有上新需求的卖家，先交付一个真实 SKU。
5. 后续再做转介绍和联盟分成，首期不投广告。

## 内容素材

- “上传一张商品图，10 分钟得到三类候选图”的演示视频。
- 同一 SKU 的原图、生成图、QC 修正和导出包案例。
- Amazon 主图规则清单和免费诊断表。

## 目标漏斗

7 天探索：20 个目标用户、5 次高清导出、2 个明确付费意向。30 天：100 个试用、10 个付费、首月收入至少 $300。60 天：300 个试用、30 个付费、MRR 约 $1,000。90 天：600 个试用、60 个付费、MRR 约 $2,500。以上是目标而非保证。

## 止损

毛利连续两周低于 60%、付费转化低于 3%、退款率高于 8%、QC 通过率低于 85%、或生成成本超过收入 35% 时，暂停投放，收窄品类、模型或试用额度。
